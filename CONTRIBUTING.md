# Contributing to Go-Redis

First off, thank you for considering contributing to Go-Redis! It's people like you that make open-source a great community.

## 🚀 How to Contribute

1.  **Fork the repository** on GitHub.
2.  **Clone your fork** locally: `git clone https://github.com/your-username/Redis.git`
3.  **Create a branch** for your feature or bug fix: `git checkout -b feature/your-feature-name`
4.  **Write code and tests**. Ensure your code adheres to Go formatting standards (`go fmt`).
5.  **Run the tests** to make sure nothing is broken: `go test ./...`
6.  **Commit your changes** with a descriptive commit message.
7.  **Push to your fork**: `git push origin feature/your-feature-name`
8.  **Open a Pull Request** against the `master` branch of this repository.

## 🐛 Reporting Bugs

If you find a bug, please open an issue using the Bug Report template. Include as much detail as possible to help us reproduce the issue.

## 💡 Suggesting Enhancements

If you have an idea for a new feature or improvement, feel free to open an issue using the Feature Request template. Let's discuss it!

## 📜 Code Style

- Follow standard Go conventions.
- Use `go fmt` to format your code.
- Ensure your code is well-commented where complex logic resides.
